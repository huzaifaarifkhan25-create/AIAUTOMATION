# What AIAutomation does

AIAutomation helps an operator find med-spa prospects, research a real operational
need and deliver one supported inquiry-follow-up automation. It joins prospect
research and service delivery in the same workspace.

Import a CSV or preview a configured browser collection. Check that each listing
is relevant; Maps can return massage spas and other businesses. Research the
official website, retain evidence and record unknowns. Public information can
support prospect fit, but only actual business confirmation establishes an
internal follow-up gap. The scores are rules for prioritizing review.

Use tasks and unsent outreach to prepare contact. The AI Agent can inspect saved
records and propose supported actions, which an operator must approve. A separate
verification checks real provider tool calling; having a key is not proof the
Agent works.

For an authorized business, deploy the fixed native n8n inquiry workflow and
connect a website form through its server. An authenticated incoming inquiry
runs through n8n, creates a follow-up task after execution is verified, and saves
the reviewed acknowledgement. Task-only mode sends nothing. Optional email mode
uses Resend with source-level approval, recipient permission and opt-out guards.
Provider acceptance and confirmed delivery are shown separately.

Outcomes show actual inquiries, tasks and email evidence. They do not claim
bookings or revenue. Accounts are individual logins in one shared workspace.
Native execution, AI, email and public hosting each need their own configured
service and verification; arbitrary workflows, calendars and dialers are outside
this build. Start with [the Windows guide](WINDOWS-START-HERE.md) and
[credential setup](docs/CREDENTIALS-SETUP.md).
